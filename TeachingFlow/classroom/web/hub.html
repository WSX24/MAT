上课

上课页 开课、与学生对话、看课件重绘与字幕。课堂在这里跑：一条 /ws 连接 = 一台状态机，不要开两个。 进入 → 课堂走向图 一条主线卡片按单元分格；支线只有一个来源——备课期 plan.json 里的预置路线（跳讲/补回头），实线画在真实岔出→汇回跨度上；导演课上现造的路线是同一种东西，画成虚线。 新标签打开 →

备课与核对

预处理 · 课件库 上传或选一份 PPT，一条链接着跑完：解析 → 备课 → 预置路线。进度与日志在页面上实时刷新；跑歪了可以只重备课、也可以拿源 pptx 重新解析，缺总结的课件就地点「补生成总结」（只写一句话总结，正文一格都不动）。 新标签打开 → 脚本审核 备课产物体检：锚点命中率、错误/告警、低置信锚点，按页列出单元与课件操作。 新标签打开 → 分支树（台账） 逐页查每个单元的分句、锚点与课件操作；分支已改由走向图承载预置路线（就地变体已停产）。走向图的竖版互补视图。 新标签打开 → 课件重绘预览 对照真实 PPT 检查解析出来的版式：元素位置、图片、分步隐藏是否正确。 新标签打开 →

接口（给外部大脑与调试用）

MCP 端点 /mcp 给 Claude 等外部大脑挂教学上下文。挂载状态看 /api/dev/mcp，接入指南见 docs/MCP接入指南.md。 打开 → /api/script/graph 走向图静态载荷：主线节点、支线 fork/merge、泳道、分支计数。 JSON → /api/script/live 运行期叠加：当前位置、被换成哪一支、池内候选三态。零副作用，每秒可拉。 JSON → /api/audit 备课体检结果（JSON），与 /review 页同源。 JSON → /api/decks 已解析的课件列表与当前 DECK_ID。 JSON →
