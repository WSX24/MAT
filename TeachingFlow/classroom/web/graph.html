这一页是只读观测面：不开课堂、不进状态机、不消费事件 —— 可以和上课页同时开着，互不影响。拖动平移、滚轮缩放；缩到 0.6× 以下卡片退化成光点， 主线本身保持屏幕 2px 粗，所以「适应全课」看到的是整门课的形状而不是一团灰。 勾掉「跟随当前」只是不再替你平移，指针照样高亮（别替我做决定 ≠ 别看当前在哪）。 学生答疑不是分支，它只是让指针临时离开主线 —— 所以气泡会写「答疑中 · 暂离主线」。

支线现在只有一种：路线分支（跳讲 / 补回头 / 提前收尾）。它跨格， 所以画的是载荷里的 fork_node → merge_node 真实跨度；chip 上写「跳讲 N 格 / 补回头 N 格 / 提前收尾 → 课尾」，点开是类型、岔出·汇回、跨格与跳过/重讲格数、时长（省·多）、理由与逐步的 steps。 路线有两个来源，几何与文案完全一致、只靠线型分开：预置路线来自备课期 （plan.json 的 routes，实线，开课前就画在这里 —— 于是这一页能回答"整门课有几条支线、 各从哪岔出、汇回哪里"），运行期路线由 C 在课上现造（虚线，选中之前还不是这门课的一部分）。 就地变体（换说法 / 举例子）已经停产（它与"学生没懂时状态机实时重讲"冲突）： 只有旧 plan.json 还带变体时，卡片角才会出现「N 支」徽标，那一栏计数也才会露出来。
