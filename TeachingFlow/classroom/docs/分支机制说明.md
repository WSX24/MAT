# 课堂分支机制说明

> 适用范围：`TeachingFlow/classroom/` 当前实现（导演层 J + Agent C + 预置路线）。
> 本文只讲**跨格路线分支**。每个单元曾经的「换说法 / 举例子」属于状态机的就地重讲链（学生没懂时实时调模型），
> 二者不是一回事；那套就地变体**已停产**（与实时重讲冲突），代码路径保留但数据里不再产出。

## 0. 一句话总览

分支只有一个数据结构（`director/route.py::Route`），只有两个来源（备课期预置 / 运行期 C 现造），
进**同一个**候选池、用**同一张**守卫表（`ROUTE_WHEN`）、被**同一个**执行器（`machine._take_route`）执行；
J（`RuleDecider`）只在单元边界上从池里挑一条，自己不做任何生成。

```
备课期  python run.py plan / routes        运行期  每 60s 唤醒一次 Agent C
        │  agent/routes.py                        │  agent/producer.py
        ▼                                         ▼
  plan.json 顶层 routes ──► LessonScript.routes ──► 候选池 CandidatePool（CAP=5）
                                                      │  when 条件 + 目标格过滤 + 排序
                                    单元边界 ┌────────┘
                                             ▼
                                     J（RuleDecider）：取第一个命中的候选
                                             │ 选中的是路线 → 交接单 payload="route"
                                             ▼
                        machine._take_route：skip 跳 / revisit 回讲 / finish 收尾
```

## 1. 分支有三种类型

| kind | 中文 | 语义 | 结构 | `est_sec` 符号 | 谁能产 |
|---|---|---|---|---|---|
| `skip` | 跳讲 | 跳过接下来若干格，从 `merge_node` 汇回主线 | `steps = []`；`merge = fork + 1 + 跳过格数` | 负数（省下的时间） | 备课期 + 运行期 |
| `revisit` | 补回头 | 回到前面讲过的格子重讲，再汇回 | `steps` 非空（要重讲的格子序列）；`merge = fork + 1` | 正数（多花的时间） | 备课期 + 运行期 |
| `finish` | 提前收尾 | 直接跳到课尾，形成不同结局 | `steps = []`；`merge = 课程总格数` | 负数（省下的时间） | **只有运行期** |

`finish` 不在备课期预置是刻意的：提前收尾看的是「当下还剩多少时间、这班跟不跟得上」，备课期这两个数不存在，
预置它等于让课程开课前就打定主意中途结束（代码里写作 `agent/routes.py` 的 `FINISH_WHY_NOT`，`when_for("finish")` 直接抛错）。

两个来源在观测面上的唯一区别是线型：**预置=实线，运行期=虚线**；几何、文案、执行完全一致。

## 2. 备课期：什么条件下预置一条分支

入口 `agent/routes.py::plan_routes(plan, deck, *, llm=None, char_warn=250)`；产物写进 `plan.json` 顶层 `routes`，
`route_id` 以 `p-` 开头（与运行期的 `r-` 区分）。稀疏铺：**每页至多一条**，真实课件 177 格铺 14 条（3.95%）。

### 2.1 revisit（补回头）铺在「这一格讲得重」的地方

| 判据 | 常量 | 说明 |
|---|---|---|
| 页内至少 3 格 | `REVISIT_MIN_UNITS = 3` | 1~2 格的页没有「本页最重」可言 |
| 主判据：该格时长 ≥ 同页中位数 × 1.5 | `REVISIT_SEC_RATIO = 1.5` | 用**比值**而不是绝对秒数（真实课件单格 3.6~29 秒，绝对值一边漏一边滥）；命中记 2 分 |
| 加分：知识点 ≥2 个 | — | 一格塞两个知识点，漏一个的概率翻倍，+1 分 |
| 加分：正文含「例句/例如/举例/example」 | `EXAMPLE_CUES` | +1 分（这类词在人教版课件里遍地都是，实测 177 格里 31 格，单独入选等于没闸门） |
| 总分 ≥2 才铺 | `REVISIT_SCORE_MIN = 2` | 时长偏重是必要条件，另两条只能加强 |

结构：`fork = 该格`，`merge = fork + 1`，`steps = [该格]`（回头把它自己再讲一遍），`est_sec = +该格时长`。

### 2.2 skip（跳讲）铺在「这几格讲的是同一件事」的地方

| 情形 | 判据 | 常量 |
|---|---|---|
| 同页同质段 | 同页相邻两格 `kp` 交集非空、连续 ≥2 格，且段起点在页内第 2 格起 | `SKIP_RUN_MIN = 2`、`SKIP_RUN_MIN_LOCAL = 1` |
| 整页同质 | 页标题含 练习/习题/答案/解析/Exercises/Practice… 且该页 ≥3 格 | `PRACTICE_CUES`、`SKIP_PAGE_MIN_UNITS = 3` |

结构：`fork = 段前一格`，`merge = 段后一格`，`steps = []`，`est_sec = -（被跳过各格时长之和）`。整页同质优先（最划算）。

### 2.3 兜底与校验

- 每条都过 `Route.validate(总格数)`：`0 ≤ fork < merge ≤ 总格数`；revisit 的 `steps` 非空且指向真实单元；结构非法**只丢不抛**并计数进 `plan.warnings`。
- `when` 与运行期是**同一张表**（`agent/producer.py::ROUTE_WHEN`），由 `tests/test_plan_routes.py` 钉住相等 —— 造它的条件就是 J 重算的条件。
- 文案（`reason` 与 `steps` 的 label/text）可由备课期 LLM 润色一次并落盘；**结构不许模型改**（模型给的 fork/merge/kind 一律无视），模型不可用时降级规则文案、备课不失败。
- 幂等：同一条走向反复算得到同一个 `p-…` id；`python run.py routes <deck>` 可对旧课件补 routes（迁移），重复跑逐字一致。

## 3. 运行期：Agent C 什么条件下现造一条分支

入口 `agent/producer.py::run_tick`（后台每 `CLASSROOM_AGENT_C_INTERVAL=60s` 醒一次，且要过门卫）。

### 3.1 触发条件表（`ROUTE_WHEN`，与 J 共用同一把尺子）

| kind | `when`（结构化条件） | 只能生产侧判的结构前置 |
|---|---|---|
| `skip` | `comprehension == confirmed` 且 `consecutive_confused <= 0` | `fork + 2 + 1 <= 总格数`（跳过去得有汇回点） |
| `revisit` | `comprehension in [vague, confused]` | `fork > 0`（前面得有可回的格） |
| `finish` | `consecutive_confused >= 3` | `fork >= 总格数 × 0.6`（还不到后段就别收尾） |

优先级 `finish > revisit > skip`（越靠后越乐观，信息不足时不该抢）；判不过就往下降级（finish 结构不成立 → 试 revisit），而不是直接放弃。

为什么阈值这么取（代码注释里的理由摘要）：跳讲会漏内容且不可逆，所以要「听懂了」**且**「一次没卡过」两个条件同时成立；
补回头花的是未来一整格的时间，只认「这一格讲完之后学生的态度」，不拿「已经重讲过几次」去触发未来再花一格；
提前收尾是三种里唯一不可挽回的，第二次卡还值得补回头，第三次才说明这条路讲不下去。

### 3.2 造出来的结构

- `skip`：`merge = min(fork + 2 + 1, 总格数)`（跳 2 格），`steps = []`，`est_sec = -Σ(被跳过格时长)`
- `revisit`：`merge = fork + 1`，`steps = [fork - 1 那一格]`，`est_sec = +该格时长`
- `finish`：`merge = 总格数`，`steps = []`，`est_sec = -Σ(剩余格时长)`

### 3.3 上货纪律（决定「造得出来但选不中」不再发生）

- **锚定当前格**：`fork_node = 当前正在讲的格`（不是未来窗口首格）。路线是「这个边界接下来往哪走」，事实来源也正好是这一格。
- `target_unit = 岔出格的下一格`（J 在边界上要选的那一格，`candidates_for` 的既有过滤天然生效）。
- `expires_at_seq = fork + 1 + EXPIRE_MARGIN_UNITS(2)`：岔出边界之后还能活两个边界（学生常常下一格才表达「没懂」）。
- 幂等键由结构派生（`r-skip-<fork>-<跨度>` / `r-revisit-<fork>` / `r-finish-<fork>`）：同一条走向反复算命中同一个 key，池按 id 覆盖、version+1。
- 同一时刻**至多 3 条路线存活**（`ROUTE_ALIVE_CAP = 3`），同 fork 才替换；超了挤掉「岔出点最早」的那条。
- 池满时的驱逐遵循**当期刚需优先**：新候选的 `expires` 严格小于牺牲品时才换（等于集中比较，不引入新时钟），且牺牲品期距不得超过 `EVICT_HORIZON_UNITS = 17`（= 上货窗口 +15 与余量 2，防哨兵值误伤）。

### 3.4 一步都不许跳的拒绝清单

`kind` 非法 / `validate` 越界 / `steps` 指向不存在的单元 / 汇回格不存在 / `when` 非法或为空 / 目标不在窗口 → 一律丢弃并记 `Rejected(payload="route")` + `agent_c_route_rejected` metric，**绝不抛异常**打断后台线程。

## 4. J 凭什么决定走哪一条

J 是 `director/decider.py::RuleDecider` —— **规则版，不调模型**（`DecisionProvider` 协议留给将来的模型版；`assembly.py` 明确「本轮没有 J 的模型版」）。

### 4.1 它能看到什么：一个 ≤100 字的事实块（`director/facts.py::DecisionFacts`）

| 字段 | 含义 | 怎么来的（`facts_from_state`） |
|---|---|---|
| `unit_id` / `slide` | 正在讲完的那一格 / 第几页 | 位置 |
| `consecutive_confused` | 连续没懂几次 | 本单元重讲轮次 `q_rounds` + 本单元还没答完的提问数 |
| `probe_result` | 最近一次页尾探针结果 | `"" / confirmed / interrupted / timeout` |
| `comprehension` | 理解信号 | 本单元相关 key 的**最坏值**：`confused > vague > confirmed`（有疑先按疑） |
| `q_rounds` | 这一格已重讲几轮 | `max(q_rounds[相关 key])` |

J 不翻状态机：状态机先把课堂压成这 100 字再交给它（延迟上界是靠输入有界换来的）。

### 4.2 候选怎么来的：三关过滤 + 排序 + 截断（`CandidatePool.candidates_for`）

1. `status == alive`；
2. `target_unit` 命中（就是「下一格」）；
3. `when` 命中 —— 扁平条件 + 隐式 AND，算子只有 `>= <= == in not_in`，空条件恒真，写错字段名的条件一律不命中（宁可漏选，不许误选）。

排序：**`agent_c` 优先**（照当下这个学生造的，比开课前批量灌的更贴题）→ 同源按新近（后造的看到的状态更完整）；
最后硬截断 `J_CANDIDATE_LIMIT = 5`（与池容量 `CAP = 5` 是两道独立保险：池子为多备货调大时，J 的输入长度不许跟着涨）。

### 4.3 拍板规则

- 取**第一个**命中条件的候选（`RuleDecider` 不重排：池子已经排过了，两处排序规则必然打架）；没有 → 返回 `None` → 课堂照常用主文 v0。
- 预取在**单元开头**发出（不 await），边界上最多补 `grace_ms`（默认 300 ms）；补不到就放弃 —— J 永不阻塞课堂。
- 每次调用恰好落在四个出口之一：`applied / none / timeout / stale`（异常另记 `error`），这四个计数器是课后唯一能复盘 J 的证据。
- **位置与目标必须和预取时一致**：学生插话导致让位/归位、翻页导致「下一格」变了 → 判 `stale`，那条货作废（用 v0）。
- 选中的若是路线，返回一张**路线交接单**（Route 全字段 + 判别键 `payload="route"`），并 `mark_consumed`；变体 dict 的形状一个字没改。

### 4.4 同一岔口上「预置」与「运行期」都在池里时谁赢

按 4.2 的排序，`agent_c` 优先 → **运行期那条被选中**；预置那条仍 alive，只是排在后面。
（要让预置优先，改的是 `director/pool.py` 的排序口径这一处。）

### 4.5 沉默的课堂不会开火

没有任何理解信号时（`comprehension == ""`），三种 `when` 一条都不命中 —— 真实课件 14 条预置支线在一节沉默的课里一条都不会被选中（实测 `applied == 0`）。
这是正确行为：没有证据就不改路线。

## 5. 执行侧：选出来不等于走得成

`machine._take_route` 是唯一执行点，任何失败都**退回 v0 + 记 `route_error`**，绝不抛异常：

| 闸 | 判据 | 失败后果 |
|---|---|---|
| `stale` | 路线的 `fork` 必须等于当前这一格 | 退回 v0（拿旧边界的决定去跳会让整段顺序错位） |
| `dup` | 同一个 `route_id` 整节课只走一次（`ROUTE_MAX_PER_ID = 1`） | 退回 v0 |
| `depth` | 不允许嵌套（重讲期间干脆不选路，`ROUTE_MAX_DEPTH = 1`） | 退回 v0 |
| `cap` | 一节课最多执行 8 条不同路线（`ROUTE_MAX_ROUTES = 8`） | 退回 v0 |
| 结构 | `Route.from_dict` + `validate` 复校 | 退回 v0 |

执行语义：`skip` 直接落到 `merge_node` 起点（中间格**一句字幕都不发、也不做课件操作**，跨页走 `_goto_slide`）；
`revisit` 清 `steps` 各格进度后回 `steps[0]` 逐字重讲，讲完显式汇回 `merge_node`；
`finish`（以及 `merge == 总格数` 的 skip）走唯一收尾入口 `_finish_all`。
记账：`state.route_log` + metrics 事件 `route_routed / route_applied / route_merged / route_refused / route_error`。

## 8. 已知边界（当前不做的事）

1. **J 不生成内容**：它只在既有候选里取第一个命中项，没有模型版；要做「按语义挑更合适的一条」需要实现 `DecisionProvider`。
2. **`finish` 不预置**，`revisit` 的支线只在备课期铺「最重的那一格」，其余靠运行期补。
3. **没有任何信号就不岔路**（见 4.5）—— 想让支线在沉默课上开火，得先让课堂产生理解信号（探针/提问/重讲）。
4. **一节课最多走 8 条路线**，且被 `skip` 越过的岔出格再也走不到（它的边界不存在了）。
5. **旧课件要迁移**：`plan.json` 里既无 `routes` 也无 `variants` 时，图上没有支线（课堂正常，只是没有岔路）。迁移命令 `python run.py routes <deck_id> [--dry-run] [--no-polish]`。
6. **卡面只显示一句总结**（≤30 字），全文要点开详情面板。总结是**备课期**顺手产的，不是运行时生成的 ——
   存量课件要 `python run.py summarize <deck_id>` 或用 `/preprocess` 页的「补生成总结」补一次，否则只能看到正文截断。
