# 课堂 · 使用说明（面向使用者）

最短路径：**启动 → 导入课件（或先出片）→ 选课程 → 上课 → 续学**。
这一份只讲"人怎么用"。契约与实现见 [正式版设计.md](正式版设计.md)，开发/排障见
[../../../README.md](../../../README.md) 与 [../README.md](../README.md)。

---

## 1. 启动

两种，任选一种（都在**仓库根** `MAT\` 下执行）：

```powershell
powershell -ExecutionPolicy Bypass -File .\start-app.ps1      # 一键：查依赖 / 查配置 / 起服务 / 自动开浏览器
python app.py                                                  # 只想看日志：起服务，不开浏览器
```

- 默认地址 **http://127.0.0.1:8000**。换端口：`$env:PORT=8010; python app.py`
  或 `powershell -File .\start-app.ps1 --port 8010`。
- 不想自动开浏览器：`--no-browser`。
- 启动横幅会写清：地址、课程库路径与课程数、引擎服务商/模型、语音开关，以及缺什么会降级。
- 停止：在跑服务的那个窗口按 **Ctrl+C**。改了 `.env` 要**重启**才生效。

## 2. 课程从哪来（两条路）

**A. 导入一份 pptx（最快）**

首页右上「导入课件」→ 选一份 `.pptx` → 立刻出现在课程库里，并且顺手备了一次课
（页数、时长、大纲可用）。这是"我只想上课，不管流水线"的路径。

**B. 先出片，再扫描**

在 `TeachingFlow` 下跑 `python flow.py "…"` 出片；产物落在
`TeachingFlow/runs/<日期>/<课程名>/`。回到首页点「重新扫描」，这些课程就进课程库
（出片后默认已经备过课）。

> 两种路最后都落到同一批产物上：`TeachingFlow/classroom/decks/<id>/deck.json`（解析）
> + `plan.json`（备课）+ `media/`（图片）。课程库里的"已准备"就是这两份文件在不在。

## 3. 主线：课程库 → 课程 → 单元 → 上课

1. **课程库**（首页 `/`）：每门课一张卡，显示单元数与学习进度。
   空库时有两个引导按钮：去出片 / 导入课件。
2. **课程详情**（`/courses/<id>`）：章 → 单元行，每行有页数、预计时长、进度，
   以及「继续」「大纲」两个入口。
3. **单元大纲**（`/units/<id>/outline`）：这单元讲什么（每页要点 + 时长）。
   想跳过前面几页？在大纲上选一页「从这里开始」。
4. **上课**（`/learn/<unitId>`）：左边是课件（按原版式重绘，讲到哪儿哪里亮），
   右边是字幕与提问框。底部控制条：暂停 / 继续 / 上一页 / 下一页 / 语速 / 全屏 / 结束课堂。
5. **课后小结**（`/sessions/<id>/summary`）：本次时长、覆盖页数、提问次数，
   以及「继续学」。

**全屏演示**：右上角 ⛶ 或控制条的「全屏」，也可以直接按 `F`。进入全屏后：

- **整个屏幕都给课件**：标题栏、侧栏、控制条全部让位；课件按 16:9 顶满，另一方向留
  等宽黑边（投影仪的标准做法，不变形）。
- 字幕叠在课件上（点浮窗里的字幕图标可以关掉）；
- **右下角出现一枚浮窗**：上一页 / 页码 / 下一页、暂停、字幕开关、提问、退出全屏。
  点「提问」展开面板，三个页签：
  - **提问**：快捷提问 + 输入框（发完自动收起，回到课件）；
  - **对话**：这一节课的全部字幕与问答回看；
  - **设置**：字幕（开关 / 字号 / 底部或顶部 / 颜色）、声音（音量 / 静音 / 语速）、
    以及浏览器挡住自动播放时的「点这里播放」。设置记在本机，下节课还是这套。
- `Esc` 先收起浮窗面板，再按一次（或点浮窗的退出键）退出全屏；按 `F` 也可以切换。
- 浏览器不允许真全屏时（外链 iframe、站点策略）会自动退化成"铺满页面"，功能够用。

**提问**：直接打字（"没听懂""举个例""再说一遍"这类也算）。老师会**先把这一句讲完**
再回应 —— 所以回答会晚几秒，这不是卡住。

## 4. 续学：关掉再进来，从上次那页接着上

- 课上到一半直接关页面 = **暂停**（不是结束）。下次进同一单元，从上次的位置接着讲。
- 认真结束（小结页「结束这节课」）之后再来，也是从上次进度接着上。
- 一个单元同时只保留一条"在上"的会话；重复进不会让课后时长翻倍。

## 5. 换档案（多个学生，无密码）

顶栏右侧可切换/新建档案。**进度是按档案分开记的**：换一个档案进同一单元，从头开始；
换回来还在原处。没有登录体系，本地多档案，删掉档案会连带删掉它的会话与进度。

## 6. 数据落位（想备份/清空时看这里）

| 东西 | 位置 | 入库吗 |
|---|---|---|
| 档案 / 课程 / 单元 / 会话 / 进度 / 事件 | `TeachingFlow/state/classroom.sqlite` | 否（运行产物） |
| 课件解析与备课产物 | `TeachingFlow/classroom/decks/<deck_id>/`（deck.json / plan.json / media/） | 否 |
| 导入的原文件 | `TeachingFlow/state/imports/<course_id>/` | 否 |
| 出片产物 | `TeachingFlow/runs/<日期>/<课程名>/` | 否 |
| 语音缓存 | `TeachingFlow/classroom/.cache/tts/` | 否 |

要"从零开始"：停服务 → 删掉 `TeachingFlow/state/classroom.sqlite` → 重启（库会自动重建）。
删课程库记录不会删 `decks/` 里的产物，想彻底重备就一并删掉对应 `decks/<id>/`。

## 7. 常见问题

**Q: 没有模型 key 会怎样？**
照样能上课，但有两处降级：① 备课走**规则兜底**（讲解基本是照读课件，不像老师讲的话）；
② 只有文字、没有语音（见下一条）。启动横幅会明说"没有可用的模型 key"。
想真备课：在 `PPT-Agent\.env` 里填 `DEEPSEEK_API_KEY`，重启，然后对这份课件重跑一次备课
（`python run.py plan <deck_id>`，或在单元页点「准备课件」）。

**Q: 只有字幕、没有声音（提示 TTS 403）？**
`edge-tts` 免费但要能连出去，且版本必须 ≥ 7.3.1（微软换了令牌算法，旧版本每一句都 403）。
升级：`python -m pip install -U "edge-tts>=7.3.1"`，重启服务。
版本太旧现在**开机就会被拦下**：启动横幅写"语音(edge-tts) 关（…太旧…）"并给出升级命令，
不会再一路静默到学生开口才发现。
升级后仍 403 通常是网络/代理问题 —— 课堂会自动降级成"只有字幕"，不影响上文。

**Q: 课程库是空的？**
①`TeachingFlow/runs/` 下还没有出片产物 → 先出片，或直接「导入课件」；
② 有产物但没扫到 → 点「重新扫描」；
③ 导入失败会给出人话原因（不是 pptx / 文件损坏 / 超过 200MB）。
`decks/` 里手动放进来的课件**不会**变成课程 —— 课程只来自 runs 与导入两条路。

**Q: 单元显示"未准备"、大纲空白？**
课件还没解析/备课成功。进单元页点「准备课件」重跑一次；仍然失败就看启动横幅与
服务窗口日志（`level=... logger=classroom.*`），常见原因是 pptx 本身损坏或没装 python-pptx。

**Q: 上课页一片空白 / 404？**
前端的产物 `TeachingFlow/classroom/webapp/dist/` 没构建。用仓库里已入库的那份即可；
自己改过前端要重新构建：`cd TeachingFlow/classroom/webapp && npm run build`。

**Q: 换了 .env 为什么不生效？**
配置只在**启动时**读一次。停服务、重启。

**Q: 想看清诊断信息（备课计划、会话事件）？**
`$env:CLASSROOM_DEV="1"; python app.py`，然后访问
`/dev/units/<unit_id>/plan`、`/dev/sessions/<session_id>/events`。默认这两个地址一律 404。
