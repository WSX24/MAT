# 课堂正式版（学生自学）· 设计文档 v1

> 状态：实施中。本文件是**唯一事实源**：后端、前端、内容管线三方都按它实现，出现冲突以本文为准。
> 主体：MAT 仓库。课堂是 MAT 的一个模块，不再自成一套工程。

## 0. 一句话

在 MAT 里启动应用 → 进课程库 → 选课程 → 看到这门课的 PPT（章/单元）→ 点进去 → 调用课堂模块 → 学生自学。
**课程来自 TeachingFlow 的 run（课程→章→单元→pptx）**，课堂引擎复用既有代码（deck 解析 / 备课 / 状态机 / TTS / MCP）。

## 1. 与原型的差别（为什么这是正式版）

| 维度 | 原原型（已废弃） | 正式版 |
|---|---|---|
| 定位 | 课堂交互原型 · 个人自学（演示品） | 学生自学产品：课程库 → 单元 → 课堂 → 续学 |
| 页面 | 6 个手写 HTML（index 单文件 104KB）+ 3 个调试页 | Vite + React + TS，5 个页面 + 设计系统 |
| 领域 | 只认 deck_id，靠 .env 切课件 | 课程(run)→章→单元(pptx) 一级对象 |
| 状态 | 进程内存，重启即丢 | sqlite：档案/课程/会话/进度/事件 |
| 调试 | /review /graph /script + /api/dev/* 裸露 | 产品内只留「单元大纲」；诊断收进 /dev（默认关） |
| 配置 | classroom/.env 与 PPT-Agent/.env 两套 | 统一读仓库根 .env（PPT-Agent/.env），启动时校验 |

## 3. 数据模型（sqlite，`TeachingFlow/state/classroom.sqlite`）

```sql
meta(key TEXT PRIMARY KEY, value TEXT);
profiles(id TEXT PK, name TEXT NOT NULL, created_at TEXT NOT NULL);
courses(id TEXT PK, title TEXT, subject TEXT, source TEXT,           -- 'run' | 'import'
        run_dir TEXT, source_path TEXT, created_at TEXT, updated_at TEXT);
units(id TEXT PK, course_id TEXT REFERENCES courses(id), chapter TEXT, title TEXT,
      order_index INT, pptx_path TEXT, slides INT, est_sec REAL,
      plan_source TEXT, prepared_at TEXT);
sessions(id TEXT PK, unit_id TEXT, profile_id TEXT,
         status TEXT,                                               -- active|paused|ended
         started_at TEXT, ended_at TEXT, elapsed_sec REAL,
         position_slide INT, position_unit INT, comprehension TEXT, qa_count INT);
progress(profile_id TEXT, unit_id TEXT, percent REAL, last_slide INT, last_unit INT,
         study_sec REAL, updated_at TEXT, PRIMARY KEY(profile_id, unit_id));
events(id INTEGER PRIMARY KEY AUTOINCREMENT, session_id TEXT, ts TEXT, kind TEXT, payload TEXT);
```
迁移：`meta.schema_version`，启动时幂等升级；不允许破坏性迁移。

## 4. HTTP 契约 v1（前缀 `/api/v1`）

**档案**
- `GET /profiles` → `{active_id, items:[{id,name,created_at}]}`
- `POST /profiles {name}` → `{id,name}`；`POST /profiles/{id}/activate` → `{ok:true}`；`DELETE /profiles/{id}`

**课程**
- `GET /courses?profile_id=` → `[{id,title,subject,source,unit_count,unit_ready_count,progress:{started,completed,percent},updated_at}]`
- `POST /courses/scan` → `{added,updated,total}`（扫描 `TeachingFlow/runs/*/`）
- `POST /courses/import`（multipart `file`）→ `{course_id,unit_id,slides}`；非 pptx → 400 + 人话
- `GET /courses/{id}` → `{id,title,subject,source,chapters:[{title,units:[{id,title,slides,est_sec,ready,plan_source,progress:{percent,last_slide,status}}]}]}`
- `DELETE /courses/{id}`

**单元**
- `GET /units/{id}` → `{id,course_id,title,slides,est_sec,ready,plan_source,progress}`
- `GET /units/{id}/outline` → `{totals:{slides,units,est_sec}, pages:[{index,title,units:[{preview,est_sec,kp:[]}]}]}`
- `POST /units/{id}/prepare` → `{ok,deck_ready,plan_ready,plan_source,degraded,warnings:[]}`（无模型 → 规则兜底，秒级）

**会话**
- `POST /sessions {unit_id, profile_id}` → `{session_id, resumed, position:{slide,unit_index}}`
- `GET /sessions/{id}` → `{id,unit_id,status,started_at,elapsed_sec,position,comprehension,qa_count}`
- `POST /sessions/{id}/end` → `{ok,recap:{elapsed_sec,slides_covered,units_given,qa_count,topics:[]}}`
- `GET /sessions/{id}/recap` → 同上 recap

**健康与静态**
- `GET /api/health` → `{ok,version,courses,engine:{provider,model,tts}}`
- `GET /` 与 `/assets/*` → `webapp/dist`

**WS** `/ws/classroom/{session_id}`
- C→S：`{t:"input",text,via?}`、`{t:"cmd",cmd:"pause"|"resume"|"next"|"prev"|"finish"}`、`{t:"rate",value:0.8|1|1.2}`、`{t:"speech_done",seq}`
- S→C（`kind` 字段）：`hello{unit,profile,position}`、`page{slide_index,slide_count,slide}`、`segment_start{seq,text}`、`audio{seq,url,b64?,mime}`、`segment_end{seq,text}`、`transcript{speaker,text}`、`state{phase,comprehension,position}`、`notify{level,text}`、`recap{...}`

**/dev（仅当 `CLASSROOM_DEV=1`）**：`GET /dev/units/{id}/plan`、`GET /dev/sessions/{id}/events`。未开启时一律 404。

**studio/materialize.py（W3）**
```python

```
**studio/outline.py（W3）**
```python
def build_outline(unit_row) -> dict     # 契约 §4 /units/{id}/outline 的形状
```

**studio/runner.py（W1）**：会话运行时，驱动既有 `course/machine`，把事件翻译成 §4 的 WS 帧，并按节流写 `progress`/`events`。

**webapp（W2）只依赖 §4 的 HTTP/WS 契约**，不读后端源码。

## 6. 前端页面

1. `/` 课程库：卡片（课程名/单元数/进度）＋空态两个 CTA（去出片 / 导入课件）＋"重新扫描"
2. `/courses/:id` 课程详情：章 → 单元行（页数/时长/进度/继续/大纲）
3. `/units/:id/outline` 大纲预览：这单元讲什么，可从某页开始
4. `/learn/:unitId` 课堂：16:9 课件重绘 + 侧栏字幕与提问 + 控制条（暂停/继续/上/下一页/语速/提问）
5. `/sessions/:id/summary` 课后小结：时长/覆盖页数/提问数/继续学
6. 顶栏：课程库 / 档案切换（本地多档案，无密码）/ 健康状态点

设计令牌：色彩/字号/间距/圆角/阴影 CSS 变量；深色+浅色；字号按投屏放大；断点 1280（投屏）/ 768（手机）。

## 7. 非目标（本期不做）

教师端、房间码、账号体系与鉴权、多机同步、课件编辑器、付费/统计后台、旧原型页面并存。

## 8. 完成标准

1. 新 clone：`python app.py` 起服务，打开即见课程库（空态有引导），健康检查 200。
2. 导入一份真实 pptx → 出现在课程库 → 进单元 → 大纲 → 开课：能听到/看到逐句讲解、能翻页、能提问并被回应、能暂停继续。
3. 退出再进同一单元 → 从上次位置续学；换档案 → 进度互不干扰。
4. API 契约测试全绿（≥25 条）；`webapp` 构建零错误、dist 入库；真实浏览器走查三条主流程通过（留截图）。
5. 引擎测试不收缩：既有引擎类用例（不含仅测旧 UI 的）100% 通过；被删除的旧 UI 用例逐条列出并说明替代覆盖。
6. 文档：本文件 + 使用说明 + 启动脚本；`python app.py` / `start-app.ps1` 两条路都能起。
