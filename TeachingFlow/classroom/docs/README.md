## 怎么读

- **只想跑起来**：先看 [`../README.md`](../README.md)（落位、`.env`、子命令、已知边界），再按需挑上面某篇。
- **要改课堂行为**：`课堂状态机规范.md` 查状态与转移 → `课堂交互设计.md` 查设计理由。
- **要接外部 Agent**：`MCP接入指南.md`；服务端代码在 [`../mcp_server.py`](../mcp_server.py)。
- **要动课件解析 / 备课**：`预处理与课件库说明.md` → `双脑三体方案设计.md`。

## 约定

- 本文档树里的代码路径一律相对 `TeachingFlow/classroom/`（即本目录的上一级）：写 `mcp_server.py` 指的就是
  `TeachingFlow/classroom/mcp_server.py`。
- 原原型仓库的启动器（`start.cmd` / `start.ps1`）和 `dbg_*` 调试脚本**没有随迁移带入**；提到它们的地方都标了「历史说明」。
- 原原型仓库的 `docs/archived/`（历史版本）**未随迁移带入**：口径可能与当前实现不一致，有疑问以代码和本文档树的现行文档为准。
