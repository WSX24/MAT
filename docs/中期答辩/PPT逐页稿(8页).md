## P5 为什么这样设计（40 s｜技术）

**页标题**：五个设计选择，各防一类失败

**一句话结论**：每条都对着一类可复现的失败，不是风格偏好。

**要点**
1. 反锚定三道：模板扫描／实际值回填／门控复检
2. 门控只做确定性判定，不含模型意见（core/llm.py:110-115）
3. 降温重试 0.7→0.4→0.0，缺陷不回投其他角色（core/llm.py:108）
4. 唯一缺陷回投是同角色重 prompt（pipeline.py:736、826）
5. 产物只认 run 内，短路径躲 260 字符上限（s5_render.py:21、105）

**证据（不上屏，备答）**：反锚定 = tools/prompt_lint.py:47 输出「✓ 反锚定检查通过」＋ s4_outline.py:136-143 按大纲实际页数回写 sidecar ＋ s4_outline.py:138 复检页数；降温阶梯 = core/llm.py:108 的 `temps=(0.7, 0.4, 0.0)`，末轮仍不过由调用方决定终止或降级（:113-114）。

**讲稿（约 105 字）**
第一，反锚定：模板不许出现示例页数，启动自动扫一遍；页数按实际回写，不把请求值当事实。第二，门控只做确定性判定，不请模型投票。第三，没过就降温重试，不把缺陷甩给别的角色；唯一一次回投，是同一角色带缺陷清单重写。第四，产物只在 run 里，短路径避开 260 字符。

**配图建议**：五行竖排，每行左一句右一条证据小字（字号 12pt 即可，不上屏也可）。

**时长**：40 s
